# Phase 2B — RX Spectrum Repeatability Summary

**Status:** PASS  
**Date:** 2026-05-10  
**Prerequisite:** Phase 2 captures present in `data/captures/`

---

## What was done

Four spectrum captures (two per device, including a `_repeat` run for each)
were loaded from `data/captures/`. Per-device statistics were computed by
grouping `pluto_a_repeat` under `pluto_a` and `pluto_b_repeat` under `pluto_b`.
The summary was written to `docs/test_logs/phase2_summary.md`.

## Key findings

- Pluto A: avg noise floor −87.87 dBFS, std dev 0.98 dB across 2 captures — **stable**
- Pluto B: avg noise floor −89.50 dBFS, std dev 1.49 dB across 2 captures — within acceptable range
- Inter-device noise floor difference: 1.63 dB — within normal unit-to-unit variation
- Peak offset consistent near +0.059 MHz across all four captures (std dev ≤ 0.001 MHz)
- The consistent ambient peak was not definitively attributed; described as possible receiver artifact or local signal

---

## Limitations

- Two captures per device is a small sample. Variability estimates are indicative only.
- All dBFS values are uncalibrated relative measurements.
- The repeatability summary is regenerated by `02_rx_repeatability_summary.py`
  and will reflect any additional captures added to `data/captures/`.

# Benchmark 2 — PLUTO-to-PLUTO Over-Air Test

**Status: PARTIALLY DEMONSTRATED — Packet link is future work**
Phase 4A (2026-05-10) demonstrated low-power over-air tone visibility at 1–3 m
benchtop range: Pluto B transmitted a CW tone at 915.1 MHz, Pluto A received
and confirmed the spectral peak via the live GUI. Result: PASS.

A full over-air link test with packet framing, CRC validation, and SNR/PER
metrics is planned for Phase 5 and has not been implemented.

See `docs/benchmark_plans/phase4_low_power_tone_plan.md` for the Phase 4A
test that partially satisfies this benchmark.
